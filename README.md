# Keybow 2040 extensions
My additions to my Keybow2040 configuration to enable things like Mouse Keys and layouts spread between files.

Layouts are in the "layouts" folder, and all they need to do is support
* setup(keybow)
* update()

There are also some utilities in layouts/key_tools.py (yes, it's not really a layout, but I just don't have the energy to put it somewhere else.
